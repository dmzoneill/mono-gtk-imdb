# imdb

The start of a Mono GTK# IMDb browser.

## What it does

So far it only opens an empty GTK# main window. No IMDb features are implemented
yet.

## Tech

- C# with Mono and GTK#

## Building

Open the `.sln` file in MonoDevelop, or build it with Mono and run the resulting
`.exe` with `mono`. Requires GTK# 2.
